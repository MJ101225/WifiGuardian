📶 WiFi na Naka-Connect Sa Laptop Mo Ngayon

1. Tignan mo sa baba-kanan, ano WiFi mo ngayon?
2. Pindutin Windows + R → type cmd → Enter
3. Type mo: netsh wlan show profile name="PANGALAN_MO" key=clear
4. Hanapin mo Key Content — yun yung password!

1. Buksan mo router mo sa baba
2. Log-in (nasa likod ng router)
